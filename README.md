# 💰 個人資產管理系統 (Asset Management)

基於 GitHub Pages 與 Supabase 開發的輕量化個人資產管理與記帳工具。

## 🌟 功能特點
* **跨裝置同步**：支援 GitHub OAuth 帳號登入，多裝置資料即時同步。
* **即時匯率**：整合 API 自動更新美元/台幣即時匯率。
* **多資產整合**：可追蹤股票/ETF、現金存款、基金、黃金與其他資產。
* **變現與記帳**：提供快速收入、支出與資產變現紀錄功能。
